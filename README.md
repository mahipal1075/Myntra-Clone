# Myntra Clone

This is a simple Myntra clone project built using React and Redux Toolkit.  
I created this project mainly to practice React concepts, Redux state management, routing, and API fetching.

The backend used in this project is very basic and only used for fetching product data because my main focus was learning frontend development with React and Redux.

---

## Features

- View products on home page
- Add product to cart
- Remove product from cart
- Add/remove directly from home page
- Cart item count update
- Calculate total MRP
- Calculate discount
- Calculate final payable amount
- React Router based navigation
- Loading spinner while fetching data
- Product data fetched from backend API
- Redux Toolkit for state management

---

## Tech Stack

- React JS
- Redux Toolkit
- React Router DOM
- JavaScript
- CSS
- bootstrap
- Node.js (basic backend for API)

---

## Project Purpose

The main purpose of this project was to learn:

- React component structure
- Redux state management
- API fetching
- Routing in React
- Managing cart logic
- Dynamic UI updates
